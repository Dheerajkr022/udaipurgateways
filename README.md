# Udaipur Gateway

> **"Independent Travel Agency, Travel Information and Courier Assistance"**

A modern, responsive, 100% informational travel advisory and courier assistance website for **Udaipur, Rajasthan**.

## Features

- **Informational Sightseeing Guides**: Detailed guides for Lake Pichola, City Palace, Fateh Sagar, Sajjangarh Monsoon Palace, and regional excursions (Kumbhalgarh Fort, Ranakpur Temples, Chittorgarh, Mount Abu).
- **Heritage Stays & Luxury Palaces**: Information on The Oberoi Udaivilas, Taj Lake Palace, The Leela Palace Udaipur, and Radisson Blu Udaipur Palace Resort.
- **Lake Cruises & Boating**: Advisory for royal sunset cruises, island palace boat rides, and solar catamarans.
- **Courier & Parcel Assistance**: Dedicated coordination for luggage, documents, and traditional Rajasthani handicraft courier forwarding.
- **100% Informational**: Purely advisory with transparent enquiry forms and zero online booking/checkout.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI & Styling**: Tailwind CSS, Lucide Icons, React Icons
- **Language**: TypeScript

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the website.
